# Media Pipeline Certification Checklist

- [ ] Query joins required media tables (STATIC)
- [ ] DB row exists with correct shape (PERSISTENCE)
- [ ] Storage object exists at declared path (PERSISTENCE)
- [ ] Public URL returns HTTP 200 (RUNTIME)
- [ ] <img>/<video> element exists in DOM (BROWSER)
- [ ] Element.naturalWidth > 0 (or videoWidth > 0) (BROWSER)
- [ ] Element.complete === true (BROWSER)
- [ ] No console errors on load (BROWSER)
- [ ] No 4xx/5xx network responses (RUNTIME)
- [ ] Mobile viewport renders correctly (BROWSER)
